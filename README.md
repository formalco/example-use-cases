# Formal example use cases

Companion repo to https://docs.formal.ai/docs/guides/example-use-cases/.

Each folder holds the files for one guide and is named after the last part of
the guide's URL. For example, `agentcore-harness-database-access` goes with
https://docs.formal.ai/docs/guides/example-use-cases/agentcore-harness-database-access.
